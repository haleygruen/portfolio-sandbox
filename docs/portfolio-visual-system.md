# Portfolio Visual System

Use these rules when creating conceptual diagrams, flowcharts, journey maps, and other public-safe case-study graphics.

## Direction

- Make each visual explain one systems idea, decision, relationship, or flow.
- Favor editorial diagrams over generic dashboard graphics or decorative illustrations.
- Use a light, warm canvas that creates a deliberate contrast with the site's dark interface.
- Use clear labels and short supporting descriptions so the visual works for a fast scan.

## Palette

- Canvas: warm off-white, approximately `#f3eee5`.
- Ink: deep blue-black, approximately `#18232b`.
- Muted text: cool gray, approximately `#68737b`.
- Accent fields: muted blush `#f3c6ce`, soft blue `#b9dce5`, and muted green `#cbdba7`.
- Use one blue-green accent, approximately `#6b9b9e`, for a shared connector, rail, or primary relationship.
- Keep color functional: each color should identify a layer, domain, or relationship rather than decorate the canvas.

## Form and composition

- Use simple original line icons to make abstract domains concrete: storefronts, diners, trucks, charts, contracts, support, or product quality.
- Use dark, rounded linework with slightly organic curves; avoid glossy effects, gradients, stock imagery, and overly precise enterprise-diagram styling.
- Prefer three clear layers, panels, or stages when the content naturally has three parts.
- Show relationships with one strong connector, rail, or shared band instead of many crossing arrows.
- Keep generous space around labels and preserve a stable aspect ratio for responsive rendering.
- Put the main idea in a short headline inside the graphic; use the caption to explain why it matters.

## Type and accessibility

- Use a restrained serif display style for the graphic headline and a plain sans-serif for labels and supporting text.
- Use uppercase tracking only for small category labels, not for paragraphs.
- Include an SVG `title` and `desc`, plus useful HTML `alt` text when the visual carries meaning.
- Keep text large enough to read at the displayed size; do not rely on color alone to distinguish domains.
- Recreate visuals as SVG when possible so they stay sharp and responsive.

## Confidentiality

- Use generalized labels and recreated diagrams only.
- Never include internal names, private screenshots, source exports, customer identities, exact metrics, or unreleased product details.
- Treat every graphic as an explanation of the public-safe story, not a faithful reproduction of the private artifact.
